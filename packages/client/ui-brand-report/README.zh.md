# 通用报告界面

[English](README.md) | 中文

## 概述

此可选的原生 Web 界面默认使用通用报告标识。侧栏与对话首页从已认证的 `/api/report-brand` 接口读取图片；应用后端可在运行时提供本地部署素材。本包不包含组织标识或内嵌的部署品牌图片。

## 使用

Web bundle 以默认禁用的 roster 行声明此包；[报告 overlay](../../../report-agent/README.zh.md) 启用它并禁用官方品牌包。界面通过等待声明的 slot 注册和中英文字典实现。查阅资料、阅读原文、附件入库和生成报告显示为业务活动；原始参数与响应保留在 Session 中，不在这些卡片中展示。

DS-Bot 界面通过公开的形状与主题注册接口接入。人物肖像只用于团队角色，设置入口使用 Lucide 齿轮。所需 SVG 路径、ISC 许可与固定版本信息在 `assets/`。侧栏标识按正方形画布的中心条带展示，模板与输入框共用居中宽度。模型目录来自原生模型服务，选择会更新对应 Bot 的持久模型配置，密钥不进入前端。`shell.overlay` 弹窗接收原生真人问题，也覆盖隐藏群聊成员的等待；没有默认答案，关闭即取消请求。首次建队可能由 DS-Bot 为每个新角色生成一次问候，后续按需调度才产生对应模型调用。

<a id="model-experience"></a>

空白对话提供六个场景入口，点击填入可编辑提示，不发送或覆盖已有自定义草稿。

## 模型体验

### 报告显示与联网偏好

#### 模型所见

此浏览器界面向宿主提交用户明确选择的联网偏好，宿主 `report-network` 插件负责模型状态与传输策略。界面不直接注册提示词或工具 schema。

#### Token 影响

活动卡片和图片不进入模型请求。首次初始化通过 DS-Bot 创建已配置的角色会话，每个新角色可能产生一次问候模型调用。之后只在角色被安排任务时增加对应的模型调用。

#### KV Cache 影响

没有直接影响；切换联网偏好会改变宿主在下一次请求提供的状态。

## 已知局限与延后工作

<a id="known-limitations-and-deferred-work"></a>

- 此可选界面需要匹配的报告后端提供运行时标识。界面负责呈现，报告事实检查和持久证据由后端负责。输入框仍保留模型选择。
