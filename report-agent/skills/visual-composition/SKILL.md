# 报告视觉编排

参考归藏 PPT Skill v1.1.0（MIT）的网格、数据大字报、页面节奏和质检原则，并结合 frontend-slides 的风格参考。源版本和许可见 UPSTREAM.json、LICENSE；当前使用共用的可编辑 PPT / HTML 渲染器，不运行上游 WebGL 或宣称兼容上游全部版式。

用户无需填写设计参数。沿用已确认的目的和读者，通过对话推荐一个方向；默认 business 蓝色商务，适合正式汇报。research 杂志研究使用暖纸色、衬线标题和低饱和强调色，适合行业研判。brief 深色科技使用深蓝底、青色强调与高反差文字，适合产品展示。

把最终方向传给 report_generate.style。不要只口头说换了风格而不传实际选项。生成前的真人卡片会显示选择，已明确的信息无需反复问。

内容优先决定版式：真实指标可形成大数字重点；枚举能力形成能力清单；长段论述拆成观点和依据；资料缺口独立说明；来源合并成引用附录。品牌头像或 logo 放在封面，不为一张标识浪费整页。一般配图采用图文组合。不要编造数据、比较关系、阶段流程或图表来填版面。

当前渲染器自动编排上述页面，不需要模型写 HTML、CSS 或坐标；PPT 保留可编辑文字与形状，HTML 使用相同页面几何。长篇 HTML 报告另有阅读目录、研究要点、分章与引用区。长段拆页，字号维持阅读下限；正文与引用保留，不隐藏内容规避排版问题。

只有工具返回 draft_ready 才提供下载链接。称为待核对初稿，说明尚需核实的来源条件；不要把版面变漂亮称为事实审核通过。
