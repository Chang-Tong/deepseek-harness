# 内容编排

按“读者要做什么决定”组织内容。先给结论和研究边界，再展开依据、场景、方案与行动建议。章节尽量三到六个，标题表达业务问题，不堆空泛的行业趋势。

先查资料库，再把每章映射到可用材料。企业宣传、规划目标、已交付实绩分开写，产品能力不能冒充市场规模，文档中未找到来源日期时说明未核实。跨文档冲突应指出口径差异，不擅自合并数字。

把拟定大纲、材料覆盖和关键缺口合成简短预览，内容明确后直接调用 report_generate，它会展示唯一的最终生成确认卡片；不要额外调用 ask_user_question 确认同一大纲。用户给过内容安排就保留它。引用使用文件名；底层原文标识由报告服务保存。
