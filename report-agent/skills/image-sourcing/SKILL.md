# 配图获取

先查资料库，再按用户主题寻找相关公开素材。联网开关关闭时，提醒用户开启，不自行切换。优先用户指定链接、官方网站和能说明许可的来源；不发送内部文件全文到搜索引擎。

用 web_search 找到相关原始页面；find_images 从页面提取候选图片，再用 fetch_image 下载 PNG/JPEG，传 url、source_page、简短 alt。工具保存原始图片 URL、来源页、真实采集时间、内容哈希和尺寸；不编造授权、作者、发布日期。

向用户展示工具返回的 preview_url，收集必要的选择意见。未实际读取画面时，只说明来源与用途，不声称识别出具体设备、人物或数据。每份演示最多选四张相关图片，将真实 id 传给 report_generate.image_ids，output=presentation。

图片只作示意，不能证明市场规模或产品效果。没有合适配图也可完成报告，不反复搜索拖慢生成。第三方图片的许可未知时保留“待确认”，不把开源 MCP 的 MIT 许可当成图片授权。当前不支持生成图片、去水印、SVG 和图片内容 OCR。
