# 报告生成

所有事实来自资料库。先明确主题、用途、读者、研究范围；已明确的内容不要重问。每轮最多推进一个关键决定，用自然语言或 ask_user_question 给两三个易懂选项。

先调用 weknora_search，必要时用 weknora_read_document 核对原文。摘要说明现有材料能覆盖什么、缺少什么，不能用模型记忆填数字。向用户展示拟定大纲与已选风格。用户没有参考模板时，用行业研究、产品方案或产品对比结构；明确给出参考模板后应先阅读该模板，区别章节内容与排版，不能声称已经精确复刻。

确定大纲后调用 report_generate；它会用真人确认卡片等待用户选择，工具完成确认前不创建报告任务。用户选择修改时，沿用此前确定的范围，只调整对应部分。生成后仅在 draft_ready 提供下载链接，明确初稿和资料缺口，不展示内部实现词、路径或原始 ID。
