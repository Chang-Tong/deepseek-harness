# 样式选择

蓝色商务 business：正式汇报的默认方向，深蓝封面、蓝色重点、清晰网格与数据大字报。
杂志研究 research：暖纸色、衬线标题和低饱和强调色，适合行业研究、内部研判与深入阅读。
深色科技 brief：深蓝底、青色强调与高反差文字，适合产品介绍和技术成果展示。

生成 PPT 或 HTML 时加载 visual-composition，按内容选择页面结构。用户已给参考报告时优先分析它；未知排版细节不要许诺复刻。用户不愿选择时采用蓝色商务，并在最终生成确认卡片中呈现。将实际选择传给 report_generate.style，不能只口头说换样式却仍用默认导出。Word 继续使用对应的通用文字版式，演示视觉主题主要作用于 PPT 和 HTML。
