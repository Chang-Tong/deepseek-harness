# 样式选择

商务汇报 business：适合领导与客户汇报，移动蓝标题、清晰层级，先结论再证据；默认推荐。
研究分析 research：适合内部研判，正文留足解释空间，强调研究范围、证据和局限。
精简纪要 brief：适合快速沟通，紧凑字号和间距，以简短段落呈现结论、依据、待办。

用户已给参考报告时优先分析它；未知排版细节不要许诺复刻。用户不愿选择时推荐一种并说明用途，在最终生成确认卡片中一并呈现。将实际选择传给 report_generate.style；不能只口头说换样式却仍用默认导出。
